### PR summaries

- **#190 (#181)** — Remote images blocked by default in preview and detail with a
  privacy notice and per-message explicit load action (re-blockable; resets on
  message switch; no global preference). `cid:` images resolve in the remote
  preview; local API URLs are exempt from blocking (absolute `VITE_API_URL` case
  covered). Imported-parts endpoint: `?load_remote_images=true` opt-in +
  `X-Mail-Blocked-Remote-Images` header; CSP sandbox unchanged; sanitization
  pinned by tests in both modes (Rust + TS). OpenAPI param emitted as optional
  query. New `docs/user-guide/mail.md`.
- **#191 (#182)** — `sort=date_desc|date_asc` on both list endpoints (invalid →
  400). SQL: `ORDER BY COALESCE(sent_at, imported_at) {dir}, id {dir}` before
  keyset pagination; new partial expression index
  `20260729000000_mail_messages_owner_sortdate_index.sql` (EXPLAIN-verified:
  index scan, no sort node, both directions). Remote: the complete matching
  mailbox is ordered by (Date, UID) before cursor pagination. Frontend sort toggle, preference persisted
  globally in localStorage; no client-side sorting.
- **#193 (#183)** — New imported-attachment download endpoint (exact bytes;
  streams the draft file-fallback path; blob path bounded by the 25 MB import
  cap); remote raw-source endpoint enabling Download .eml in the three-pane
  viewer; one shared Content-Disposition sanitizer (ASCII fallback + RFC 5987
  Unicode, extension-preserving truncation, Windows reserved names, injection
  negative tests); missing-object classification (only confirmed-missing → 404,
  infrastructure errors → 5xx).
- **#194 (#184)** — Archive wired into toolbar + bulk bar (role-derived
  destination, clear error when absent); COPY+delete fallback for MOVE-less
  UIDPLUS servers; `MailError::PartialMove` (actionable 502) for
  copied-but-not-deleted (COPYUID unobtainable in async-imap 0.11.2 —
  documented); per-item bulk failure summaries with selection retention;
  duplicate-submission guards; single-action failures surface server errors.
- **#195 (#185)** — Backend CAS save verified correct, unchanged. Frontend:
  structured 409 propagation (`current_rev`, `server_sha256`); unsaved-changes
  guards (beforeunload + beforeNavigate + file-switch confirm); conflict panel
  (Copy / Download / confirmed Reload; Save disabled until resolved);
  identical-content suppression (fails visible); tombstone-409 recovery panel.
- **#197 (#186)** — Bug-bash audit: 21 findings (12 FIX / 4 DEFER / 5
  DISMISSED), 8 runtime-verified with Playwright (desktop + 390px, light/dark).
  All 12 FIX findings implemented, one commit each (WB-001…WB-012): login error
  copy, dashboard grammar + share names, toolbar a11y, note header at 390px,
  saved-mail reachable without IMAP account, mail list-state retention, bulk-bar
  wrap, attachment chip truncation, shares page 390px, responsive admin sidebar,
  unified date/time formatting.
- **#198 (#154/#132)** — Empty-means-unset for bootstrap passwords (random
  one-shot password now works via compose defaults); pre-flight documented as
  required; smoke script gains /health + /health/ready + share revocation and no
  longer executes `.env` or violates double-submit CSRF; bucket bootstrap
  distinguishes NotFound from unreachable/forbidden (actionable startup errors);
  backend healthcheck + restart policies; one-shot admin password documented.

Final review also fixed three integration defects before merge: remote IMAP sorting

Vault `beforeNavigate` hook was moved to component initialization (#195), and the
admin module table now keeps every field reachable at narrow widths (#197). Quoted

## 3. Impact assessments

- **Privacy (#190):** reading HTML mail never contacts external image servers
  before explicit per-message approval, in any view. Marker attribute is inert.
  Reviewer focus documented in the PR body.
- **Security (#193):** all download paths share one Content-Disposition builder;
  header-injection/traversal negative tests; no storage-key exposure; cross-tenant
  404 on the new endpoint (deliberate asymmetry flagged for review).
- **Data safety (#195):** no path overwrites a newer server revision from the
  WebUI; unsaved content recoverable after conflicts, failures, and navigation;
  GC/writer-lock work from PRs 175–178 intact (object_gc suite 8/8 live).
- **Compatibility:** mail list default stays newest-first (now by message date —
  the deliberate change specified by #182); omitted `sort` keeps working; no
  breaking API changes; one additive migration (index only). Vault save contract
  unchanged; sync clients learn WebUI edits via manifest (live-tested).
