# RustShare v0.7.0 WebUI Bug Bash — Phase 6 Audit (Issue #186)

Date: 2026-07-29
Baseline commit: `12becc0d` (main, merge of PR #178)
Branch: `fix/webui-polish-186`
Scope: GitHub issue #186 — bounded WebUI bug bash across Login, Dashboard, Files,
Notes, Mail, Vault, Sharing/public shares, Administration, Settings, and the
error/not-found pages.

This document records confirmed defects only. Each finding lists whether it was
verified against the running application (runtime-verified) or deterministically
from source (code-verified). No production code was changed for this audit.

---

## Method

### Runtime pass (executed)

- Local stack: `docker compose` PostgreSQL + RustFS + backend + nginx already
  running (healthy). Frontend served from a **vite dev server on current source**
  (`VITE_API_URL=/api/v1`, port 5173, same-origin proxy via nginx), so runtime
  evidence reflects the code at `12becc0d`, not a stale built bundle.
- Audit user `bugbash@audit.local` (admin) seeded directly; data seeded via the
  public API: files (normal, 200 kB binary, 110-char filename), a folder with a
  90-char name, two notes (one with a 200-char title), two imported `.eml`
  messages (one with a 120-char subject and a 70-char attachment filename), one
  public share link, one vault.
- Playwright (chromium 149) drove every screen at 1440x900 and 390x844, light
  and dark color schemes, plus wrong-password login, empty-form submit, missing
  note (error state), invalid share token, and unknown route (404). DOM probes
  measured horizontal overflow at 390px.
- Screenshots: `/tmp/wb-shots/*.png` (scratch dir outside the repo, **not
  committed**, per bug-bash rules; filenames cited per finding).

### Code-level pass (executed)

- Each screen's components checked against the state matrix: loading / empty /
  error / disabled-in-progress / long text / narrow width / focus + accessible
  names / theme.
- All known candidates from the v0.7.0 baseline audit verified or dismissed
  (see "Known candidate verification" at the end).

### Not auditable in this environment

- **Mail three-pane with a live IMAP account** (no IMAP server available):
  remote message list, preview pane, compose, and bulk actions were audited
  code-only. Findings WB-006 and WB-007 are therefore code-verified.
- **OIDC login variant** (no IdP configured); password login was audited live.
- **Folder-type public share page** and **Shared-with-me populated** (seed had
  a file share only; Shared-with-me redirects to `/files?root=shared` and was
  empty for the audit user).
- Module apps outside the required list (Kanban, Meetings, Decisions,
  Brainstorming, Standups) were not covered.
