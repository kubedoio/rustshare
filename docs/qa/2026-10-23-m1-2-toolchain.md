## Drift guard and review

`scripts/check_rust_toolchain.py` uses Python 3.11's standard library. It checks
tracked and unignored workflow/build selectors against the canonical channel,
checks MSRV does not exceed it, and requires full Dependabot compiler ignores.
`scripts/test_check_rust_toolchain.py` creates temporary Git repositories and
tests positive configuration plus deliberately inconsistent selections through
the CLI's failing exit status. It includes new workflow/Dockerfile pins,
floating selectors, Cargo/compiler overrides, and removal of update ignores.

Independent review reproduced missed ordinary Cargo overrides in the first
version; regression fixtures now cover those forms. This static guard cannot
evaluate arbitrary generated shell or third-party installer behavior. Reviewers
must extend the guard when introducing a new compiler-selection mechanism.

Configuration and guard changes received separate subagent review; the crypto
feature fix received an independent security review. Human review remains
required before merge because the bounded fix touches a cryptographic dependency
feature. No merge, deployment, or institutional Gate A is part of this change.

## PR #400 OsRng reproduction and bounded fix

With rustc 1.97.1, before the fix:

```bash
cargo test --locked -p rustshare-crypto --lib
```

exited 101 with E0432 in `backend/crates/crypto/src/password.rs`: the
`argon2::password_hash::rand_core::OsRng` import was configured out because
`rand_core` 0.6.4 lacked `getrandom`. This is production code compiled for the
package tests; workspace feature unification can hide this missing feature.

A separate bounded commit enables `argon2`'s `std` feature in the crypto
package manifest. The feature chain is `argon2/std -> password-hash/std ->
rand_core/std -> getrandom`. Existing OS-backed salt generation, Argon2
parameters, public APIs, and error behavior are preserved. No test was disabled.
The same command then passed all 17 tests, including wrong-password rejection
and distinct salts. Package Clippy with all targets/features also passed.
CI runs the isolated package test before workspace Clippy to retain coverage of
the package's own dependency feature closure.
