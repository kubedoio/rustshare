## Implementation and acceptance scope

P4.3c adds the smallest UI/search integration supported by these existing contracts. Search authorization and snippet materialization stay in the current unified-search endpoint. Historical links are provenance only and are independently resolved at use time. Tests will target the current Calendar, meeting resource, Decision, Action, and unified-search HTTP harnesses, with particular attention to hidden candidates and revocation. Broad operational Gate A evidence (production deployment, independent operator rehearsal, backup/restore, upgrade/rollback, and a 10–15-user pilot) is outside repository tests and remains required before any Gate A claim.

## Explicit limits to validate against the implementation

- Meeting action titles/descriptions remain in their existing action table and become candidates only through the current unified-search handler after live meeting-folder authorization.
- A linked Calendar event is included in search navigation only after Calendar authorizes it for the current user.
- Historical provenance may point to an unavailable source; that state must not expose its title, path, content, or resource reference.
- No new database table or object-storage format is planned.
